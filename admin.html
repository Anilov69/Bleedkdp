How do I get a token? (one-time, 2 minutes)
  1. Open GitHub → New fine-grained token.
  2. Name it e.g. Store admin and choose an expiration (e.g. 1 year).
  3. Under Repository access choose Only select repositories → Bleedkdp.
  4. Under Permissions → Repository permissions set Contents to Read and write.
  5. Click Generate token, copy it and paste it above.

The token is stored only in this browser. Anyone without it can't change your store.
